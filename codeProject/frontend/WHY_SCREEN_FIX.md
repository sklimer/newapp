# Исправление белого экрана в приложении

## Проблема
Приложение показывало белый экран при открытии в обычном браузере, вместо основного интерфейса.

## Причина
В файле `src/App.tsx` была реализована проверка на запуск в Telegram Web App. Если приложение запускалось не в Telegram, то отображалось сообщение "Application Access Denied" вместо основного интерфейса.

## Решение
Были внесены изменения в файл `src/App.tsx`:
1. Убрано блокирующее сообщение при открытии в обычном браузере
2. Добавлено предупреждение в консоль о том, что приложение разработано для Telegram
3. Приложение продолжает работать и отображает основной интерфейс даже вне Telegram
4. Сохранена логика проверки Telegram Web App для совместимости

Теперь приложение может быть запущено и протестировано в обычном браузере, хотя все равно рекомендуется использовать его в Telegram Web App для полного функционала.
